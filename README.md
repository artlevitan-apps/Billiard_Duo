# Геворк Бильярдинский 3.0 — Russian Pyramid + 8-Ball

Игровой проект для TCL Android TV / Google TV. Офлайн, управление одним телевизионным пультом, два игрока за одним столом или игра с компьютером. Android-приложение — полноэкранная WebView-оболочка, игровая логика локальная JavaScript, музыка и фото включены в APK.

## Выбор режима

1. На главном экране выберите **1 игрок** или **2 игрока**.
2. Выберите **Русский бильярд (пирамида)** или **Пул 8-ball**.
3. На экране обозначены имена **ГЕВОРКИУС** и **МАРИО**. При одном игроке Марио — компьютер.

## Два вида бильярда

- **Русская пирамида — домашняя комбинированная версия.** Одна выделенная золотой точкой белая битковая шара и 15 светлых прицельных шаров. За легально забитый прицельный шар — 1 очко; за правильно забитый биток после касания прицельного шара («свояк») — тоже 1 очко, после чего биток возвращается на стол. Первый, набравший 8 очков, побеждает. Это упрощённая версия, а не официальный спортивный регламент.
- **8-ball.** Сплошные 1–7, полосатые 9–15, чёрная 8, белый биток. Первый правильно забитый шар определяет группу. После забития группы игрок заказывает лузу для 8. Раннее или ошибочное забитие 8 — штраф и возврат восьмёрки на стол, а не автоматическое поражение (домашнее правило).

В обоих режимах есть штрафы с размещением битка, передача хода, до 60 секунд на удар с сигналами последних 10 секунд, пауза и фото Геворка с поздравлением победителю.

## Управление пультом TCL

| Кнопка | Действие |
|---|---|
| Короткое ← / → | Очень точный поворот прицела **0,12°** за нажатие |
| Удержание ← / → | Ускоренный поворот; короткие нажатия дают точную доводку |
| ↑ | **Накат** (+6% за нажатие): биток старается идти вперёд после первого удара по шару |
| ↓ | **Оттяжка** (−6%): после контакта биток может откатиться назад |
| OK удерживать | Сила **один раз** плавно растёт от 0 до 100% за ~1,75 с, затем остаётся на максимуме |
| OK отпустить | Удар |
| Back / Play-Pause | Пауза; повторное Back сразу продолжает |

При **свободном битке** стрелки выбирают положение, OK подтверждает. При **заказе восьмёрки** стрелки выбирают лузу с подсветкой, OK подтверждает.

### Траектории

- Белая пунктирная линия — **геометрический луч** до поверхности первого шара или до борта (до конца препятствия, независимо от мощности).
- Бирюзовая — **прогноз движения первого задетого прицельного шара**.
- Оранжевая — **прогноз движения самого битка** после столкновения либо отскока; накат и оттяжка меняют её.

Динамика прогноза и реальная физика используют общую модель. Предсказание рассчитано для примерно **60% силы**, если шкала не зажата; при наборе силы оно пересчитывается. Это игровой 2D-симулятор с моделированием трения/отскока/вращения, но не профессиональная 3D-физика бильярда: очень сложные множественные столкновения могут отличаться от прогноза.

## Как получить APK автоматически без Android Studio

В ZIP **уже есть** `.github/workflows/build-apk.yml` с событием `push` на `main`: если эта папка действительно загружена в GitHub, сборка стартует после **Commit changes** сама.

**ВАЖНО ДЛЯ MAC:** Finder скрывает папки, начинающиеся с точки (это не наш выбор: GitHub Actions требует путь **`.github/workflows/`**). После распаковки ZIP в Finder нажмите **⌘ Command + ⇧ Shift + .** — появится `.github`. На GitHub нужно загрузить содержимое распакованной папки **включая эту папку**. На вкладке `Code` должна открываться папка `.github`, а внутри неё `workflows/build-apk.yml`.

В новом приватном репозитории: `Add file` → `Upload files` → перетащить все элементы из Finder, включая `.github` → `Commit changes` → `Actions` → дождаться зелёной галочки → `Artifacts` → скачать архив `Gevork-Billiardinsky-v3-APK` → распаковать `app-debug.apk`.

В уже существующем репозитории замените папку `app`, файлы `build.gradle`, `settings.gradle` и `gradle.properties` (или загрузите те же пути поверх старых). Рабочий workflow `.github` оставьте на месте, либо замените его новым. Если удаляли/создавали репозиторий, важно вернуть `.github`!

**Подпись APK:** GitHub создаёт debug APK на временном сервере. Если у старой установленной версии другая debug-подпись, Android не даст установить v3 поверх неё. В таком случае нужно удалить старую игру с ТВ и установить новую — сохранения старой версии будут потеряны.

## Сборка и файлы

- `app/src/main/assets/index.html` — интерфейс;
- `app/src/main/assets/game.js` — правила, физика, траектории, AI, управление;
- `app/src/main/assets/club-lounge.mp3` — тихая фоновая клубная музыка (отключается);
- `app/src/main/assets/dad.jpg` — портрет Геворка;
- `app/src/main/java/.../MainActivity.java` — перевод клавиш TCL в команды игры;
- `.github/workflows/build-apk.yml` — GitHub Actions, автоматически собирает `app-debug.apk`.

Нужны Java 17 и Android SDK 35 при локальной сборке. Игра не требует интернета на ТВ. Не содержит рекламы.

## Что проверено

Проверены синтаксис JS (`node --check`), логика выбора обоих режимов, прицел с малым шагом, вращение и изменения траекторий, старт удара при отпускании OK, предел силы, экран паузы, работа DOM в Chromium. Сам APK не собран и не проверен на реальном TCL в этой среде; гарантии отсутствия ошибок для каждой модели ТВ нет.
