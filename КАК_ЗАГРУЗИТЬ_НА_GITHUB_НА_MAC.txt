ГЕВОРК БИЛЬЯРДИНСКИЙ 3.0 — ЗАГРУЗКА В GITHUB С МАКА

1. Распакуй ZIP.
2. Открой распакованную папку в Finder.
3. Нажми одновременно Command + Shift + . (точка).
   Теперь станет видна папка .github — именно она запускает сборку APK.
4. Создай новый приватный репозиторий на github.com/new.
5. В GitHub нажми uploading an existing file или Add file -> Upload files.
6. В Finder выдели ВСЁ содержимое распакованной папки, включая .github.
   Перетащи файлы в окно Chrome. Нельзя загрузить ZIP одним файлом,
   необходимо именно распакованное содержимое.
7. Commit changes. Переходи в Actions: сборка стартует автоматически.
8. Когда появится зелёная галочка, скачай Artifacts / Gevork-Billiardinsky-v3-APK.
   Внутри app-debug.apk.

Если GitHub показывает "Get started with GitHub Actions", значит .github не загрузилась.
Проверь в Code, есть ли .github/workflows/build-apk.yml.
GitHub требует ТОЧНО это название скрытой папки, менять его нельзя.

Для обновления старой игры с другой подписью APK, возможно, придётся удалить
старую установку с телевизора перед установкой новой.
